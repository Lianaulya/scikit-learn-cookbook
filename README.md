## 🔬 Ringkasan Teoretis Setiap Bab

### Chapter 01: API Elements of scikit-learn
- **Estimator API**: Pola desain `fit(X, y)` untuk melatih model berdasarkan data.
- **Transformer API**: Pola desain `transform(X)` dan `fit_transform(X)` untuk manipulasi data fitur.
- **Predictor API**: Metode `predict(X)` dan `predict_proba(X)` untuk inferensi data baru.
- **Pipeline & ColumnTransformer**: Membungkus langkah-langkah preprocessing dan modeling menjadi satu objek reusable yang mencegah data leakage.

### Chapter 02: Data Preprocessing
- **Penskalaan Fitur**: 
  - `StandardScaler`: $z = \frac{x - \mu}{\sigma}$ (cocok untuk distribusi normal).
  - `MinMaxScaler`: $x_{norm} = \frac{x - x_{min}}{x_{max} - x_{min}}$ (skala 0 sampai 1).
  - `RobustScaler`: Menggunakan median dan IQR, tahan terhadap outlier.
- **Encoding Kategorik**: `OneHotEncoder` untuk nominal data dan `OrdinalEncoder` untuk data berurutan.
- **Imputasi Data Hilang**: `SimpleImputer` (mean/median/most_frequent) dan `KNNImputer`.

### Chapter 03: Dimensionality Reduction
- **Principal Component Analysis (PCA)**: Dekomposisi ortogonal matriks kovarian untuk memaksimalkan variansi data:
  $$\mathbf{\Sigma} = \frac{1}{n} \mathbf{X}^\top \mathbf{X} = \mathbf{V} \mathbf{\Lambda} \mathbf{V}^\top$$
- **Linear Discriminant Analysis (LDA)**: Reduksi terarah (supervised) yang memaksimalkan separabilitas antar-kelas.
- **t-SNE & Kernel PCA**: Menangkap struktur manifold non-linier untuk visualisasi data dimensi tinggi.

### Chapter 04: Models with Distance Metrics and Nearest Neighbors
- **K-Nearest Neighbors (KNN)**: Algoritma berbasis instansi (instance-based learning):
  $$\hat{y} = \text{mode}\big(\{y_i : x_i \in N_k(x)\}\big)$$
- **Struktur Indeks Geometri**: `KDTree` dan `BallTree` untuk mempercepat pencarian tetangga terdekat dari $O(N)$ menjadi $O(\log N)$.
- **Metrik Jarak**: Euclidean ($L_2$), Manhattan ($L_1$), Minkowski ($L_p$), dan Mahalanobis.

### Chapter 05: Linear Models and Regularization
- **Ordinary Least Squares (OLS)**: Meminimalkan Residual Sum of Squares (RSS):
  $$\min_{\mathbf{w}} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2$$
- **Ridge Regression ($L_2$)**: Mencegah multikolinieritas dan overfitting:
  $$\min_{\mathbf{w}} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \alpha \|\mathbf{w}\|_2^2$$
- **Lasso Regression ($L_1$)**: Menghasilkan bobot sparse (seleksi fitur otomatis):
  $$\min_{\mathbf{w}} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \alpha \|\mathbf{w}\|_1$$
- **ElasticNet**: Kombinasi konveks penalti $L_1$ dan $L_2$.

### Chapter 06: Advanced Logistic Regression
- **Fungsi Sigmoid / Logit**:
  $$P(Y=1|X) = \frac{1}{1 + e^{-\mathbf{w}^\top \mathbf{X}}}$$
- **Log Loss / Binary Cross-Entropy**: Fungsi biaya berbasis Maximum Likelihood Estimation (MLE).
- **Multiclass Strategies**: One-vs-Rest (OvR) dan Multinomial (Softmax).
- **Evaluasi**: Kurva ROC, area di bawah kurva (AUC), dan kurva Precision-Recall.

### Chapter 07: Support Vector Machines and Kernel Methods
- **Max-Margin Classifier**: Mencari hyperplane pemisah optimal dengan meminimalkan:
  $$\min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2 + C \sum_{i} \xi_i$$
- **Kernel Trick**: Menghitung produk skalar di ruang fitur dimensi tinggi tanpa perlu memetakan data secara eksplisit:
  - RBF (Radial Basis Function): $K(x, x') = \exp(-\gamma \|x - x'\|^2)$
  - Polynomial: $K(x, x') = (\gamma x^\top x' + r)^d$

### Chapter 08: Tree-Based Algorithms and Ensemble Methods
- **Decision Trees**: Pemisahan rekursif berbasis Gini Impurity $I_G = 1 - \sum p_i^2$ atau Entropy $H = -\sum p_i \log_2 p_i$.
- **Random Forest**: Bagging (Bootstrap Aggregating) + random feature subspace sampling untuk menurunkan variansi model.
- **Boosting**: Penambahan model sekuensial untuk mengoreksi residual sebelumnya (AdaBoost, Gradient Boosting).

### Chapter 09: Text Processing and Multiclass Classification
- **Representasi Teks**: Bag of Words (`CountVectorizer`), N-grams, dan Term Frequency-Inverse Document Frequency (`TfidfVectorizer`):
  $$\text{tf-idf}(t, d, D) = \text{tf}(t, d) \times \log\left(\frac{1 + |D|}{1 + |\{d \in D : t \in d\}|}\right) + 1$$
- **Naive Bayes Classifier**: MultinomialNB berbasis teorema probabilitas Bayes dengan asumsi independensi bersyarat antar kata.

### Chapter 10: Clustering Techniques
- **K-Means Clustering**: Partisi data menjadi $K$ cluster dengan meminimalkan Within-Cluster Sum of Squares (WCSS).
- **Penentuan K Optimal**: Elbow Method dan Silhouette Coefficient:
  $$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$
- **DBSCAN**: Clustering berbasis densitas, mampu menemukan bentuk non-globular dan mendeteksi noise data.
- **Hierarchical Clustering**: Agglomerative clustering dengan visualisasi dendrogram.

### Chapter 11: Novelty and Outlier Detection
- **Isolation Forest**: Memisahkan anomali berdasarkan kedalaman isolasi pada pohon biner acak (outlier memerlukan lebih sedikit pemotongan).
- **One-Class SVM**: Memetakan data ke ruang berdimensi tinggi dan memisahkan kelas normal dari titik asal.
- **Local Outlier Factor (LOF)**: Mengukur deviasi kepadatan lokal suatu titik relatif terhadap tetangganya.

### Chapter 12: Cross-Validation and Model Evaluation
- **Validasi Silang (CV)**: $K$-Fold dan Stratified $K$-Fold untuk memastikan estimasi performa yang tidak bias.
- **Pencarian Hiperparameter**:
  - `GridSearchCV`: Evaluasi kombinasi grid secara exhaustif.
  - `RandomizedSearchCV`: Sampling acak dari distribusi parameter yang efisien secara komputasi.
- **Kurva Evaluasi**: Learning Curve untuk mendeteksi bias vs. varians dan Validation Curve.

### Chapter 13: Deploying Models in Production
- **Serialisasi Model**: Penyimpanan pipeline terlatih menggunakan `joblib.dump` dan `joblib.load`.
- **Reproducibility Pipeline**: Memastikan transformer input dan predictor terikat dalam satu file pipeline konsisten.
- **Inferensi Baru**: Penyiapan API endpoint untuk menerima data payload JSON dan menghasilkan prediksi secara real-time.
